# There — анонимный мессенджер на карте

Продуктовая спецификация v1. Источник: рассказ автора (2026-11-07) и дизайн `There.sketch` (экраны выгружены в `design/screens/`).

## Идея

Полностью анонимный мессенджер без регистрации. Чаты и каналы привязаны к точке на карте и видны только при сильном приближении. Человек открывает приложение, видит свой район и чаты в нём — или их отсутствие. Можно уехать картой куда угодно (Эйфелева башня, Пиза), но чаты видны только «вблизи».

## Идентичность

- Никакой регистрации, ни имени, ни телефона, ни e-mail.
- Сервер знает об устройстве ровно два идентификатора:
  1. **Device ID** — чтобы при следующем запуске показать пользователю его чаты.
  2. **Push-токен** (APNs / FCM) — только если пользователь разрешил уведомления.
- **Имя задаётся отдельно в каждом чате** при вступлении или создании. Можно каждый раз новое, можно одно и то же — выбор пользователя. По умолчанию предлагаем случайное имя из списка ~1000 известных киноперсонажей.
- Имя уникально среди участников одного чата (чтобы нельзя было выдать себя за другого).
- Над полем ввода всегда видно текущее имя пользователя в этом чате.
- Пользователь может переименоваться. **Старые сообщения сохраняют старое имя** — имя записывается в сообщение в момент отправки.

## Карта

- При запуске карта центрируется на текущем местоположении (если дано разрешение).
- Чаты и каналы видны только начиная с определённого уровня приближения (примерно «видны здания»). При отдалении они просто исчезают — никаких кластеров и счётчиков «в Париже 300 чатов».
- На шкале зума показываем, с какого уровня появляются чаты.
- Чаты в одной или почти в одной точке: не накладываем иконки, а показываем один маркер, по нажатию — попап со списком (со скроллом).
- Скрытые чаты на карте видят только их участники.
- *Будущая монетизация (не v1):* платная видимость канала на более далёком зуме.

## Чаты и каналы

| | Чат | Канал |
|---|---|---|
| Кто пишет | все участники | только админы/модераторы |
| Реакции | все участники | все участники |

У каждого чата: название (до 32 символов), иконка — один эмодзи, координаты, и настройки:

- **Свободный вход** — или вход по заявке, которую одобряют.
- **Премодерация** — новое сообщение видят только автор и админы; остальные видят, что сообщение есть, но не его текст, пока админ не одобрит.
- **Видим всем** — или скрытый: попасть можно только по ссылке / QR-коду (`https://there-chat.com/<код>`).

## Участие

- Свободный чат: можно читать без вступления; «Join This Chat» → выбор имени → участник.
- Закрытый чат: содержимое не видно; «Send a Request to Join» → заявка видна во вкладке *Pending* списка участников → одобрение или отказ.
- Роли: **owner** (создатель), **admin**, **member**. Статусы: pending, active, left, blocked.
- Участник может выйти из чата.

## Сообщения

- Только текст. Никаких картинок, файлов, голосовых, видео и даже автоподсветки ссылок.
- Реакции эмодзи: нажатие на сообщение → выбор эмодзи.
- В ленте: разделители по датам, системные события (вступил, запросил вступление, вышел), удалённые сообщения показываются плашкой «Message deleted at HH:MM».

## Модерация

Админы могут:
- удалить сообщение;
- удалить все сообщения участника;
- заблокировать участника (блокировка привязана к устройству — с другого устройства человек придёт как новый, это осознанное ограничение);
- одобрять заявки и сообщения в премодерации;
- повышать участника до админа;
- менять настройки чата, удалять чат.

**Обязательно для App Store / Google Play** (правило 1.2 App Review для приложений с пользовательским контентом): кнопка «пожаловаться» на сообщение/чат, возможность скрыть пользователя, и механизм реакции на жалобы со стороны сервиса (минимальная админка у нас).

## Уведомления

- Включаются/выключаются для каждого чата.
- Экран «Notifications» — лента событий (в дизайне пока копия «My Chats», нужно проработать).

## Экраны (по дизайну)

1. Главный: карта, настройки, уведомления, зум, «моё местоположение», New Chat, My Chats (счётчик).
2. Новый чат: перетаскиваем карту для выбора точки + шторка с параметрами.
3. Чат: лента, ввод с текущим именем, меню чата.
4. Реакции на сообщение.
5. Инфо чата: карта-шапка, QR, уведомления, участники (All / Pending / Active).
6. Действия над участником: переименовать, сделать админом, удалить все сообщения, заблокировать.
7. Настройки чата + удаление.
8. Ссылка / QR-код.
9. My Chats (Chats / Channels).
10. Вход в открытый чат / заявка в закрытый.
11. Уведомления.

Отсутствуют в дизайне: онбординг (разрешения геолокации и уведомлений), выбор имени при вступлении, настройки приложения (шестерёнка), жалобы.

## Вне рамок v1

Медиа и файлы, форматирование, ссылки, монетизация, синхронизация между устройствами, сквозное шифрование.

## Принятые решения

- **Идентичность устройства:** ключ генерируется на устройстве и хранится в Keychain (iOS) / Block Store (Android) — переживает переустановку и перенос из бэкапа. Сервер знает только публичный ключ.
- **Заявки на вступление** одобряют только админы.
- **Карта:** MapKit на iOS, Google Maps (maps-compose) на Android.
- **Сервер:** Go, SQLite (WAL) на старте, один дроплет DigitalOcean. SQL пишем так, чтобы переезд на PostgreSQL был механическим.

## Открытые вопросы

- Можно ли создать чат в любой точке мира или только рядом с собой?
- Что происходит с пустыми / заброшенными чатами (автоудаление через N дней без активности?).
- Минимальное расстояние между чатами или всегда группировка в попап?
- Лимиты против спама: сколько чатов может создать одно устройство, частота сообщений.
- Может ли админ переименовать участника (в дизайне есть «Rename…»)?
