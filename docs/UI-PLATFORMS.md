# UI: iOS 26 (Liquid Glass) и Android (Material 3 Expressive)

Принцип: на каждой платформе — родные компоненты. Общими остаются палитра, иконки, тексты и поведение, но не внешний вид элементов управления. Дизайн из `There.sketch` (2024) — референс по структуре и смыслу, а не попиксельно.

## Общие токены

| Токен | Значение | Где |
|---|---|---|
| accent | `#264BCA` | кнопки, переключатели, свои ссылки, маркеры |
| text-primary | `#121E49` | основной текст |
| text-secondary | `#949BB4` | подписи, время, системные события |
| surface-muted | `#F2F4FA` | фон ленты, поля ввода |
| reaction-bg | `#FFF9E4` / рамка `#A04D07` | плашка реакций |
| danger | `#C41111` | удаление, блокировка, бейдж |

Шрифты: iOS — системный SF Pro (Dynamic Type), Android — Roboto (системный, с поддержкой масштабирования шрифта). Нужна тёмная тема — в дизайне её нет, выведем из палитры.

## Соответствие элементов

| Элемент дизайна | iOS 26 (SwiftUI) | Android (Compose, Material 3) | Доработка на Android |
|---|---|---|---|
| Кнопки поверх карты (настройки, колокольчик, зум, геопозиция) | `.buttonStyle(.glass)`, `GlassEffectContainer` | `FilledTonalIconButton` / `SmallFloatingActionButton` | полупрозрачность и размытие фона — библиотека Haze, иначе просто `surfaceContainer` с тенью |
| New Chat / My Chats внизу | glass-кнопки или `.toolbar` в нижней панели | `HorizontalFloatingToolbar` (M3 Expressive) или два `ExtendedFloatingActionButton` | минимальная |
| Шторка нового чата и настроек | `.sheet` + `.presentationDetents([.medium, .large])` — в iOS 26 на среднем детенте сама «отрывается» от краёв, стекло | `ModalBottomSheet` | М3-шторка всегда во всю ширину; «парящая» с отступами — кастом, обычно не нужно |
| Меню чата «⋯», действия над участником | `Menu` — стеклянное меню-поповер от кнопки (вместо action sheet) | `DropdownMenu` (в Expressive — с группами и разделителями) | нет |
| Подтверждения «Удалить чат?», «Заблокировать?» | `.confirmationDialog` (в iOS 26 — поповер у кнопки) | `AlertDialog` | нет |
| Переключатель Chat / Channel, вкладки участников | `Picker(.segmented)` | `SingleChoiceSegmentedButtonRow` или `ButtonGroup` (connected) | нет |
| Переключатели настроек | `Toggle` | `Switch` | нет |
| Поле названия + иконка-эмодзи | `TextField` + кнопка, открывающая эмодзи-клавиатуру | `OutlinedTextField` + кнопка | выбор одного эмодзи — `EmojiPickerView` из androidx через `AndroidView` |
| Список «My Chats» с бейджами | `List` + `.badge` | `LazyColumn` + `ListItem` + `Badge` | нет |
| Заголовок большой «My Chats» | `.navigationTitle` + `.large` | `LargeTopAppBar` / `MediumFlexibleTopAppBar` | нет |
| Пузыри сообщений, плашка реакций, системные события | свои вью | свои composable | кастом на обеих платформах |
| Поле ввода с именем над ним | `TextField(axis: .vertical)` + стеклянная кнопка отправки | `TextField` + `IconButton` | кастом на обеих |
| Выбор реакции | своя стеклянная панель частых эмодзи + полный выбор | своя панель + `EmojiPickerView` | кастом |
| QR-код | CoreImage `CIQRCodeGenerator` | библиотека ZXing core | — |
| Шапка с картой в инфо чата | `Map` со статичной камерой | статичная карта | — |

## Карта

Ключевое решение, от него зависит внешний вид маркеров и стиль карты:

- **Нативные карты** (MapKit на iOS, Google Maps Compose на Android): лучше всего вписываются в систему, бесплатно на iOS; на Android нужен ключ Google Cloud и биллинг (бесплатного объёма для Maps SDK на мобильных обычно хватает). Стили на iOS почти не настраиваются.
- **MapLibre** на обеих платформах + векторные тайлы (например, MapTiler, Stadia или свой хостинг OpenMapTiles): одинаковый стиль везде, полностью свой дизайн карты, но тайлы стоят денег или нужен свой хостинг.

Скрытие чатов при отдалении и группировка близких маркеров в попап делаются на клиенте одинаково для любого варианта: сервер отдаёт чаты в видимой области, только если зум ≥ порога.
